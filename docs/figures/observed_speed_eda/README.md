# 실제 관측속도 EDA

전체 보고서 배치 순서와 그림별 상세 해석은 [docs/EDA_GUIDE.md](../../EDA_GUIDE.md)를 함께 참고한다.

이 폴더의 그림은 `seoul_link_speed_fact.csv`에 기록된 **실제 관측속도**(`평균속도`)만 사용한다. 대상은 관측 가능한 A 링크이며, 2026-07-07 01:00부터 2026-07-20 23:00까지의 335시간, 15,049,459 링크-시간 행이다. A lookup이나 B/C 예측속도는 이 분석에 들어가지 않는다.

모든 평균은 별도 언급이 없으면 링크-시간 행 기준 평균이다. 따라서 이 그림들은 관계 탐색용 EDA이며, 인과관계를 단정하지 않는다.

| 그림 | 무엇을 보여주는가 | 읽는 법과 주의점 |
| --- | --- | --- |

| `03_observed_speed_hour_profile.png` | 평일과 주말의 시간대별 실제 평균속도 | 새벽·오전첨두·낮·오후첨두 패턴이 실제로 존재하는지 보여준다. 이후 속도 모델이 복원해야 할 목표 패턴이다. |
| `04_observed_speed_distribution.png` | 실제 시간평균속도의 분포 | 고정 링크 표본의 전 시간대를 사용한다. 주된 속도 범위와 극단 저속·고속값을 확인한다. |

## 보고서에서의 역할

이 묶음은 “실제 교통속도에 어떤 시간·도로·강수 패턴이 존재하는가”를 설명하는 근거다. 전 링크 예측 EDA보다 먼저 배치한다. 특히 `02`, `03`, `05 또는 06`, `08`을 본문 핵심 그림으로 권장하고, 나머지는 피처 선택 근거나 부록으로 사용한다.
