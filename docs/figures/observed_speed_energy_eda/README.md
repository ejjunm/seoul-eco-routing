# 관측속도 기반 추정 에너지 EDA

전체 보고서 배치 순서와 그림별 상세 해석은 [docs/EDA_GUIDE.md](../../EDA_GUIDE.md)를 함께 참고한다.

이 폴더는 실제 A 링크 관측속도를 VT-CPEM에 입력해 계산한 **관측속도 기반 추정 에너지**를 분석한다. 에너지 자체를 차량에서 직접 계측한 것은 아니다. 입력 속도만 실제 관측이며, 링크 길이·경사도·구름저항·공기저항·700W 보조전력을 사용한 물리모델 계산값이다.

- 대상: 2026-07-07 01:00~2026-07-20 23:00, 관측 A 링크
- `Wh per link`: 링크를 한 번 통과할 때의 총에너지. 링크 길이 영향을 받는다.
- `Wh/km`: 길이를 보정한 에너지 원단위. 도로 효율 비교에 적합하다.
- 경사도 양수: 링크 진행방향 기준 오르막. 음수: 내리막.
- 회생제동은 기본 모형에 적용하지 않았다. 내리막도 보조전력 때문에 에너지가 0이 되지 않는다.

## 보고서에서의 역할

이 묶음은 “관측된 속도 패턴이 전기차 에너지 비용으로 어떻게 이어지는가”를 설명한다. 본문에는 `01`, `03`, `04`, `09`를 우선 사용하고, 도로등급·강수·분포 그림은 보조 근거로 사용한다.
