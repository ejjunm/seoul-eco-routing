# 전 링크 예측속도·에너지 EDA

전체 보고서 배치 순서와 그림별 상세 해석은 [docs/EDA_GUIDE.md](../../EDA_GUIDE.md)를 함께 참고한다.

이 폴더는 `all_link_speed_prediction_*` 및 `link_energy/link_energy_*`에서 만든 **서울 전 링크(63,548개) A/B/C 혼합 예측속도와 VT-CPEM 에너지**를 분석한다. 실제 관측속도만 쓰는 `observed_speed_eda/`와 달리, 관측되지 않은 링크도 B/C 모델 예측으로 포함한다.

- 분석 기간: 2026-07-07 01:00~2026-07-20 23:00, 총 335시간. 7/7 00:00은 제외했다.
- A: 관측 이력 lookup, B: 이웃속도 포함 모델, C: 정적 피처 모델.
- `Wh/km`는 길이를 보정한 에너지 원단위이고, 실제 경로 비용은 링크별 총에너지(`energy_ev_wh` 또는 `energy_ev_j`)를 써야 한다.
- 에너지는 속도·길이·진행방향 경사도를 VT-CPEM에 넣은 추정치다. 차량 실측 전력량은 아니다.

## 보고서에서의 역할

이 묶음은 관측 EDA 다음에 배치한다. 먼저 실제 A 링크에서 속도·에너지 관계를 확인하고, 그 다음 이 그림으로 **전 네트워크에 확장된 예측 결과와 에너지 비용 구조**를 설명한다. 본문 핵심 그림은 `01`, `05`, `06`, `10 또는 11`을 권장한다.
