# 실제 관측값과 A lookup 비교

전체 보고서 배치 순서와 그림별 상세 해석은 [docs/EDA_GUIDE.md](../../EDA_GUIDE.md)를 함께 참고한다.

이 폴더는 같은 A 링크·같은 시각에서 실제 관측속도(A-Observed)와 `model_a_lookup.parquet`의 A lookup 속도를 비교한다.

A lookup은 링크×시간×평일/주말별 과거 관측 평균이다. 따라서 미래 시점의 이력 기반 추정에는 쓸 수 있지만, 해당 날짜·시간의 실제 관측값과 동일하지 않다. 이 결과는 같은 기간의 일치도를 보는 진단이며, 누수 없이 분리한 공식 시간 분할 성능평가를 대체하지 않는다.

## 핵심 수치와 활용

현재 335시간 비교에서 A lookup과 실제 관측속도의 평균 MAE는 약 2.54km/h, RMSE는 약 4.30km/h다. 이 값은 같은 기간 내 진단값이다.

과거 7/7~7/20을 재현하는 에너지·라우팅 분석에서는 `data/processed/historical_hybrid_link_energy/`를 사용한다. 이 파일은 실제 관측 A 링크를 우선 사용하고, 관측이 없는 순간의 A 링크만 lookup으로 보완하며, B/C 링크는 기존 모델 예측을 유지한다. 미래 시점 예측 분석에는 이 하이브리드가 아니라 전 링크 A/B/C 예측 파일을 사용해야 한다.
