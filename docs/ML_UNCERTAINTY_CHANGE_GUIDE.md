# ML 불확실성 브랜치 변경사항과 결과 해석

기준 브랜치: `feature/maeul-bus-carbon` (`7e97d30`)  
확장 브랜치: `feature/ml-uncertainty-hdbscan`

이 문서는 기존 마을버스 분석과 비교해 무엇이 바뀌었는지, 각 변경이 왜 필요한지,
그리고 현재 결과에서 실제로 어떤 결론을 낼 수 있는지를 설명한다.

## 1. 핵심 요약

| 구분 | 기존 분석 | 확장 분석 |
| --- | --- | --- |
| 속도예측 | 링크별 속도 한 값 | 하한·중앙·상한 속도 |
| 모델 평가 | 중앙예측 오차 중심 | 중앙예측 오차 + 예측구간 포함률 + 구간 폭 |
| 데이터 분할 | 기존 검증 방식 | 링크 단위 학습·보정·시험 완전 분리 |
| 노선 탄소 | 하나의 탄소 추정값 | 속도 불확실성을 전달한 탄소 민감도 범위 |
| 정책 4분류 | 노선당 분류 하나 | 하한·상한 조건에서도 분류가 유지되는지 표시 |
| 노선 유형 | K-means가 모든 노선을 지정 군집에 배정 | HDBSCAN이 자연 군집과 비정형 노선을 구분 |
| 결과물 | 기존 표와 분석 문서 | 발표용 PNG 12장, 독립 HTML, 상세 CSV 생성 코드 |

새 기능은 별도 스크립트로 추가했기 때문에 기존 파이프라인과 병합 충돌 가능성이 낮다.

## 2. 속도예측: 한 값에서 하한·중앙·상한으로

기존 모델은 특정 링크·시간대의 속도를 하나의 대표값으로 예측한다.

```text
기존: 예상속도 = 23km/h
```

이 값만으로는 실제 속도가 얼마나 흔들릴 수 있는지 알 수 없다. 새 분석은 Quantile XGBoost로
5%, 50%, 95% 분위수를 예측한다.

```text
변경: 하한 14km/h | 중앙 23km/h | 상한 35km/h
```

- 하한은 느린 상황을 반영한다.
- 중앙은 대표적인 속도예측이다.
- 상한은 빠른 상황을 반영한다.

이 범위는 교통상황이 변했을 때 전기버스 에너지와 탄소 결과가 얼마나 달라질 수 있는지를
계산하기 위한 입력으로 사용한다. 기존 Model A/B/C를 없앤 것이 아니라, 동일한 B/C 구조를
분위수 예측으로 확장한 별도 모델이다.

구현: `src/models/05_build_speed_uncertainty.py`

## 3. 모델 평가: MAE와 함께 포함률·구간 폭 평가

MAE는 중앙예측과 실제속도의 평균적인 차이다. 예를 들어 실제속도 20km/h를 25km/h로
예측했다면 절대오차는 5km/h다. 새 모델의 별도 시험 링크 기준 중앙예측 MAE는
**5.11km/h**다.

구간예측에는 MAE 외에도 두 지표가 필요하다.

### 포함률

실제속도가 예측 하한과 상한 사이에 들어온 비율이다.

```text
예측구간 14~35km/h, 실제 28km/h → 포함
예측구간 14~35km/h, 실제 42km/h → 미포함
```

목표는 90% 구간이다. 시험 데이터 결과는 다음과 같다.

| 구분 | 포함률 |
| --- | ---: |
| 목표 | 90.0% |
| 원시 Quantile XGBoost | 88.9% |
| Split Conformal 보정 후 | **92.7%** |

Conformal 보정은 calibration 데이터에서 실제값이 구간을 얼마나 벗어나는지 측정한 뒤,
유한 표본 보정을 사용해 하한과 상한을 확장한다.

### 구간 폭

포함률만 높이려면 무조건 넓은 구간을 만들면 되므로, 구간 폭도 함께 확인해야 한다.
현재 보정 구간의 평균 폭은 **26.93km/h**다. 목표 포함률은 달성했지만 폭이 넓으므로
현재 결과는 정밀한 예측구간보다는 보수적인 위험 범위에 가깝다.

## 4. 데이터 분할: 링크 단위 학습·보정·시험 분리

한 도로 링크에는 여러 날짜와 시간대의 관측이 반복된다. 행을 무작위로 나누면 같은 링크의
월요일 기록이 학습 데이터에, 화요일 기록이 시험 데이터에 들어갈 수 있다. 모델은 이미 해당
링크의 정적 특성과 속도 패턴을 본 상태이므로 시험 성능이 실제보다 좋아질 위험이 있다.

새 분석은 `LINK_ID` 단위로 데이터를 분리한다.

```text
Train       → Quantile XGBoost 학습
Calibration → Conformal 구간 보정량 계산
Test        → 학습과 보정이 끝난 뒤 최종 평가
```

기본 실행에서 사용한 표본은 다음과 같다.

- 학습 링크 1,200개
- calibration 링크 350개
- 시험 링크 350개
- 시험 관측치 117,600개

같은 링크가 두 집합에 동시에 포함되지 않는다. 이웃 링크 속도 피처도 학습 링크만 원천으로
사용하여 시험 링크의 실제속도가 간접적으로 유입되는 것을 막았다.

## 5. 노선 탄소: 점추정에서 민감도 범위로

기존 분석은 대표속도 하나로 VT-CPEM 에너지를 계산하고, 이를 버스 탄소와 승객·km당 탄소로
환산했다. 새 분석은 속도 하한·중앙·상한에서 에너지를 각각 계산한다.

```text
속도 하한 ─┐
중앙속도 ──┼→ VT-CPEM → 에너지 최솟값·중앙값·최댓값
속도 상한 ─┘             → 버스 탄소범위 → 승용차 대비 탄소비율 범위
```

에너지는 속도에 단순 비례하지 않는다. 저속에서는 운행시간과 보조전력이 커질 수 있고,
고속에서는 공기저항이 커질 수 있다. 따라서 속도 하한을 곧바로 에너지 하한으로 간주하지
않고 세 속도에서 계산한 에너지의 실제 최솟값과 최댓값을 사용한다.

승용차 대비 비율은 다음처럼 읽는다.

```text
버스/승용차 < 1 → 버스 우위
버스/승용차 = 1 → 동일
버스/승용차 > 1 → 승용차 우위
```

유효한 230개 노선의 결과는 다음과 같다.

| 판정 | 노선 수 | 비율 | 의미 |
| --- | ---: | ---: | --- |
| 전 범위에서 버스 우위 | **192** | **83.5%** | 보수적 조건에서도 버스 탄소효율이 좋음 |
| 경계·불확실 | **33** | **14.3%** | 조건에 따라 결론이 바뀔 수 있음 |
| 전 범위에서 승용차 우위 | **5** | **2.2%** | 적재량·운행·차량 조건을 우선 점검해야 함 |

전 범위에서 승용차 우위로 나온 노선은 서초05, 성북06, 중랑01, 성북05, 동작10이다.
이는 노선 폐지 결론이 아니라, 낮은 평균 탑승량과 운행조건을 포함한 입력자료를 먼저 확인할
대상이라는 뜻이다.

구현: `src/transit/12_route_carbon_uncertainty.py`

주의: 이 범위는 링크 단위 conformal 속도구간을 모델 등급·시간대별로 요약해 노선에 전달한
**보수적 민감도 범위**다. 노선 단위 90% 확률구간으로 해석하면 안 된다.

## 6. 정책 4분류: 현재 분류와 분류 안정성 구분

기존 정책 4분류는 교통약자·대중교통 의존도와 승객당 탄소효율을 조합한다.

| 분류 | 교통 의존도 | 탄소효율 | 기본 정책 해석 |
| --- | --- | --- | --- |
| 1 | 높음 | 좋음 | 증편·지원 |
| 2 | 높음 | 나쁨 | 소형차 전환 |
| 3 | 낮음 | 좋음 | 현행 유지 |
| 4 | 낮음 | 나쁨 | 조정 검토 |

새 분석은 에너지 하한과 상한에서 각각 분류를 다시 계산한다. 두 조건에서 분류가 같으면
`class_stable=True`, 다르면 정책 경계 노선으로 표시한다.

```text
하한 1번, 상한 1번 → 분류 안정
하한 1번, 상한 2번 → 분류 경계
하한 3번, 상한 4번 → 분류 경계
```

의존도 점수는 고정하고 탄소효율만 변화시키므로 이동은 1↔2 또는 3↔4 방향에서 발생한다.

| 결과 | 노선 수 | 비율 |
| --- | ---: | ---: |
| 분류 안정 | **100** | **43.5%** |
| 분류 경계 | **130** | **56.5%** |

세부적으로 에너지 조건에 따라 67개 노선은 1→2, 63개 노선은 3→4로 이동할 수 있다.
따라서 현재 4분류를 확정적인 정책 처방으로 바로 사용하는 것은 위험하며, 경계 노선에는
실차 에너지·충전량·시간대별 탑승량 자료가 더 필요하다.

## 7. HDBSCAN: 자연 군집이 실제로 존재하는지 검증

기존 K-means는 모든 노선을 지정된 군집에 넣는다. HDBSCAN은 군집 수를 미리 고정하지 않고,
밀도가 낮은 노선을 비정형 또는 노이즈로 남길 수 있다.

고령인구, 대체수단 없는 승차, 탄소, 승용차 보유, 하루 승차, 경사, 1차로 비중,
주간 속도와 운행횟수 등 10개 특성을 표준화했다. 여러 설정을 비교하고 80% 부분표본을
20번 다시 뽑아 군집의 반복 안정성도 확인했다.

결과는 다음과 같다.

- 진단용 군집 2개
- 군집 포함 102개
- 비정형·노이즈 128개, 55.7%
- silhouette 0.138
- bootstrap ARI 0.000
- 기존 정책분류와의 ARI 0.015

따라서 현재 변수에서는 안정적인 자연 군집이 확인되지 않았다. 이 결과는 실패라기보다,
노선을 데이터만으로 몇 가지 고정 유형에 나누어 정책에 바로 사용하는 것이 타당하지 않다는
근거다. 기존 정책 4분류를 대체하지 않고 진단 자료로만 사용한다.

구현: `src/transit/11_route_typology_hdbscan.py`

## 8. 결과가 의미 있는가?

결론은 **의미 있는 결과가 나왔지만, 의미의 종류를 구분해야 한다**는 것이다.

### 의미가 큰 결과

1. **전체 노선의 83.5%가 보수적 범위에서도 버스 우위다.**  
   한 개의 속도 추정값에만 의존하지 않아도 192개 노선의 탄소 우위가 유지된다. 마을버스의
   탄소효과가 일부 가정에만 의해 만들어진 결과는 아니라는 근거가 된다.

2. **정책분류의 56.5%가 경계다.**  
   기존 점추정 분류가 실제보다 확정적으로 보였음을 보여준다. 130개 노선은 실차자료 확인 없이
   곧바로 증편·감편·차량변경 결론을 내리면 안 된다.

3. **우선 검토 대상을 구체적으로 좁혔다.**  
   버스 우위가 안정적이고 일일 감축량도 큰 관악02-1, 노원15, 강서01, 서초18, 강동05는
   효과가 견고한 사례다. 반대로 서초05, 성북05, 중랑01, 동작10, 성북06은 입력자료와 운행조건을
   먼저 확인할 대상이다.

4. **HDBSCAN의 부정적 결과도 의미가 있다.**  
   현재 10개 변수로는 재현 가능한 자연 노선 유형이 없다는 점을 수치로 확인했다. 군집 결과를
   억지로 정책 유형으로 포장하지 않을 수 있게 됐다.

5. **모델 성능보다 정책결론의 견고성을 평가할 수 있게 됐다.**  
   MAE 하나만 제시하는 것보다, 예측 오차가 최종 탄소·정책 판단을 바꾸는지를 직접 보여준다.

### 과장하면 안 되는 결과

- 평균 탑승인원과 버스/승용차 탄소비율의 Spearman 상관계수는 -0.98이지만, 승객당 탄소
  계산식에 탑승인원이 직접 들어가므로 새로운 인과관계 발견은 아니다. 운영상 탑승률이 중요한
  지렛대라는 확인 결과로 해석해야 한다.
- Conformal 구간은 포함률 목표를 충족하지만 평균 폭이 넓다. 정밀한 속도 예측 완성보다
  불확실성을 보수적으로 드러낸 결과다.
- 실차 SOC, 충전전력, 냉난방, 차량별 중량 데이터가 없으므로 전기버스 에너지 절대값의
  현장 정확도가 새로 검증된 것은 아니다.
- 경유·CNG 환산과 차량 구성비 등 기존 탄소모델의 가정은 그대로다. 이번 작업이 개선한 것은
  주로 **속도 불확실성이 최종 결론에 미치는 영향**이다.

## 11. 최종 결론

이번 확장의 가장 중요한 성과는 예측모델을 복잡하게 만든 것이 아니라 다음 질문에 답할 수
있게 된 것이다.

> 속도예측의 오차를 고려해도 노선의 탄소효과와 정책분류가 유지되는가?

탄소 우위는 다수 노선에서 견고했지만, 정책 4분류는 절반 이상이 경계였다. 따라서 발표에서는
“마을버스의 탄소효과가 확인됐다”와 “모든 노선의 정책처방이 확정됐다”를 구분해야 한다.
현재 결과는 전체적인 탄소효과를 지지하면서도, 노선별 정책결정에는 추가 실차자료가 필요한
대상을 명확하게 제시한다.
